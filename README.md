# ORRERY — Solar System Explorer

A lightweight, interactive solar system visualization that runs directly in your browser. No build tools or dependencies required.

## Run it

Open `index.html` in a modern web browser. For a local server, you can also run:

```bash
python -m http.server 8000
```

Then visit <http://localhost:8000>.

## Explore

- Watch all eight planets orbit the Sun.
- Select a planet to see a short description and key facts.
- Pause or resume the simulation, adjust its speed, or reset it.
- Use the layout on desktop or mobile screens.

Planet sizes and orbital distances are illustrative and are not to scale. The interface uses the Manrope and DM Mono fonts from Google Fonts when an internet connection is available; fallback fonts are used otherwise.
